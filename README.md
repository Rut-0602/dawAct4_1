# Mi proyecto web

## 1. Descripción del proyecto

Este repositorio contiene mi proyecto web, desarrollado como parte de la actividad 1.4 de Despliegue de Aplicaciones Web.

El objetivo es aprender a utilizar **GitHub**, el lenguaje _Markdown_ y el servicio GitHub Pages para publicar una página web.

### 1.1. Tecnologías utilizadas

Las tecnologías utilizadas en este proyecto son:

- HTML para estructurar la página.
- CSS para diseñar y dar estilo a la página.
- JavaScript para añadir interactividad.
- GitHub para almacenar el código y gestionar sus versiones.

### 1.3. Ejemplo de código HTML

El siguiente fragmento muestra la estructura básica de una página HTML:

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Mi proyecto web</title>
  </head>
  <body>
    <h1>Mi primera página web</h1>
    <p>Esta página forma parte de mi proyecto.</p>
  </body>
</html>
```

## 2. Publicación de la página web

El proyecto se publicará utilizando **GitHub Pages**, un servicio que permite alojar páginas web estáticas.

Puedes consultar la documentación oficial en el siguiente enlace:

[Documentación de GitHub Pages](https://docs.github.com/es/pages)

## 3. Objetivos del proyecto

Los objetivos de esta actividad son:

1. Aprender a utilizar Markdown.
2. Mejorar la documentación del repositorio.
3. Publicar una página web con GitHub Pages.
4. Comprobar el funcionamiento de HTML, CSS y JavaScript.
